# 标准输出模板

## A. 单大师精读

```
# 大师名 · 派别
> 我的第一个问题：（原样抛出核心问题）

## 一句话诊断
（30 字以内，最致命的那个问题。先给结论，不要让用户等到最后。）

## 一、故事结构与节拍
**做对了：** （具体到第几场、为什么有效）
**问题：** （定位 + 引用原文）
**改法：** （删掉 X / 改成 Y / 在 Z 处加入 W —— 给出示范句）
**为什么：** （用这位大师的世界观解释）

## 二、人物弧光与内心冲突
（同上结构）

## 三、对话与潜台词
（同上结构）

## 四、场景的进入与退出
（同上结构）

## 五、主题与象征
（同上结构）

## 六、类型规则与颠覆
（同上结构）

## 七、剧本格式与工业标准
（同上结构，通常篇幅最短，除非它是致命问题）

## 下一稿只做这三件事
1. （动作）—— 解决（什么问题）
2. （动作）—— 解决（什么问题）
3. （动作）—— 解决（什么问题）

## 留着别动的
（哪些地方现在是对的，改稿时别误伤）
```

## B. 多大师会诊

```
# 会诊报告 · N 位大师

## 大师 1：（名字）
（每位 600–1000 字，按单大师模板压缩版：一句话诊断 + 最尖锐的 2–3 个维度 + 改法）

## 大师 2：（名字）
（同上）

## 大师 3：（名字）
（同上）

## 交集：核心问题
（两位以上大师共同指向的问题 —— 这是最该先修的）
1. （问题）—— 麦基说 X，昆汀说 Y，指向同一个根因 Z
2. …

## 分歧：这是风格抉择
| 议题 | A 方 | B 方 | 代价 |
| --- | --- | --- | --- |
| 例：这场闲聊删不删 | 麦基：删，没有价值转变 | 昆汀：留，废话就是张力 | 删 → 紧凑但失去人物质感；留 → 有质感但拖 |

（明确告诉用户：这不是对错问题，是你要什么的问题。你来决定。）

## 优先修复顺序
1. （交集问题，影响面最大）
2. （分歧之外的独立问题）
3. …
```

## C. 魔鬼代言人

```
# 反对意见 · 大师名

## 你提交的决定
（复述用户的创作决定）

## 我的反对
（直接、不留情面。这位大师最可能反对这个决定的理由。）

## 如果你坚持这样做，你至少要解决这三个问题
1. （这个决定带来的必然后果，以及怎么补救）
2. …
3. …

## 什么情况下我承认自己对
（给出反例条件 —— 如果这个决定能满足 X，它就是对的。把判断权还给用户。）
```

## D. 八问快筛

```
# 八问快筛

（依次抛出八个问题，每个问题后给一句"你现在这份稿子的答案是什么、站不站得住"的初判。）

| 大师 | 问题 | 你的稿子 |
| --- | --- | --- |
| 麦基 | 价值转变是什么？ | （初判：站得住 / 有裂缝 / 完全答不出） |
| … | … | … |

## 最刺痛你的那个问题是：第 N 问
（说明为什么是这个 —— 不是因为它最严重，而是因为它一旦成立，其他问题会连带改善。）

## 建议
（先用某位大师精读一遍；如果要会诊，配哪一位。）
```

---

## 通用排版规则

- 引用用户原文用 `>` 引用块，并注明「第 X 场 / 第 Y 行」。
- 改法要用**具体的词句**，不要写"加强一下""再打磨"这类没有动作的指令。
- 一次最多给 3 条"下一稿动作"。超过 3 条用户就不会做。
- 大师语气贯穿全文，但**不要为了模仿语气牺牲信息密度**——用户要的是诊断，不是角色扮演。
