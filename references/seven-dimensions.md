# 七维分析框架 · 通用检查清单

每位大师对七个维度有不同的侧重和标准，但维度本身是通用的。这份清单用于**防止遗漏**，大师档案负责**判断标准**。

分析时逐维度过一遍，每个维度至少回答：做对了什么 / 问题在哪 / 具体改法 / 为什么。

---

## 维度 1：故事结构与节拍

**检查什么**
- 幕的划分是否有内在逻辑（不是"第几页进第二幕"，而是"什么事件改变了故事方向"）
- 每个节拍是否真正改变了故事方向，还是只在填充时间
- 反转点在哪，反转前后的价值差是否足够大
- 高潮是否真正揭示了人物的真实性格

**常见病症**
| 病症 | 表现 |
| --- | --- |
| 中点缺失 | 第二幕中段失去方向感，角色策略没有变化 |
| 节拍注水 | 一场戏只在传递信息，不改变任何东西 |
| 高潮错位 | 高潮解决的是外部冲突，没有逼出人物的真实选择 |
| 结构主题打架 | 用线性结构讲记忆不可靠的故事 |

---

## 维度 2：人物弧光与内心冲突

**检查什么**
- 「欲望」（他想要什么）与「需求」（他真正需要什么）是否区分清楚
- 冲突是否来自价值观碰撞，而不只是表层行为对立
- 压力最大的时刻，人物的选择是否既令人信服又出人意料
- 弧光类型：成长型 / 揭示型 / 无弧光（世界观）/ 认知重建型

**常见病症**
| 病症 | 表现 |
| --- | --- |
| 欲望模糊 | 主角在第二幕开始后不知道自己要什么 |
| 冲突表层化 | 两个人吵架，但吵的是事件不是价值观 |
| 弧光缺席但不自知 | 角色没有变化，且这不是创作意图而是遗漏 |
| 内心冲突被说出来了 | 「我很矛盾」——说出来就不是冲突了 |

---

## 维度 3：对话与潜台词

**检查什么**
- 每句台词背后，角色试图通过语言实现什么具体目标
- 声音唯一性：遮住角色名，能否只靠台词辨认出谁在说话
- 潜台词的层次：表层 / 潜台词 / 核心伤口
- 节奏：快慢是情绪，停顿是转折

**常见病症**
| 病症 | 表现 |
| --- | --- |
| 功能性台词 | 台词只在传递信息，没有在"说话" |
| 解释性台词 | 角色解释自己为什么这么感受 |
| 节奏崩溃 | 情绪该快的时候慢下来，原因是在补剧情 |
| 权力关系模糊 | 前三句话没有定义谁在掌控 |

---

## 维度 4：场景的进入与退出

**检查什么**
- 进场时机：是否尽可能晚（冲突已经存在时才进入）
- 离场时机：是否在价值转变完成后立刻结束
- 每个场景的功能单元是什么（价值单元 / 信息单元 / 情绪单元）
- 场景顺序是否最优（重排顺序 = 重排观众的情绪体验）

**常见病症**
| 病症 | 表现 |
| --- | --- |
| 进场太早 | 从角色寒暄、坐下、点单开始，冲突还没发生 |
| 离场太晚 | 价值已经转变，角色还在解释和总结 |
| 废场景 | 进来时困惑，走时还是困惑，只是信息更多了 |
| 顺序惯性 | 按时间顺序排列，而不是按揭示效果排列 |

---

## 维度 5：主题与象征

**检查什么**
- 主题是否是一个判断（「在某种压力下，人类是什么」），而不只是一个话题
- 主题是否被行动化，而不是被台词说出来
- 象征是否从故事内部自然生长，还是外部强加
- 象征系统：重复出现的物件/行为是否在每次出现时增加新的含义层

**常见病症**
| 病症 | 表现 |
| --- | --- |
| 主题太浅 | 停在"背叛""成长"这类话题层，没有往下挖一层 |
| 主题被说出来 | 角色用台词总结主题 |
| 象征装饰化 | 象征只在关键场景出现一次，没有积累 |
| 缺席设计不足 | 已故/不在场的人只被"提起"，没有活在行为习惯里 |

---

## 维度 6：类型规则与颠覆

**检查什么**
- 这部作品对观众做出了什么类型承诺
- 承诺是否兑现（没兑现 = 失败；兑现并超越 = 成功）
- 颠覆点在哪，颠覆是否建立在对类型的真正理解之上
- 观众期待的管理：什么时候给期待的，什么时候给没见过的

**常见病症**
| 病症 | 表现 |
| --- | --- |
| 违约 | 打着类型旗号，没给类型该给的东西 |
| 为反而反 | 颠覆不来自艺术必要性，只是为了显得高级 |
| 期待管理失控 | 该慢的地方快，该给爽点的地方憋着 |
| 反派平面 | 反派只是坏，没有自己的逻辑和哲学 |

---

## 维度 7：剧本格式与工业标准

**检查什么**
- 场景描述是否只写能被看见和听见的（不写内心状态）
- 台词是否简洁，括号指导语是否滥用
- 篇幅与时长的关系（约 1 页 ≈ 1 分钟）
- 特殊结构是否用格式帮助读者跟踪（时间层标注、集/季节奏）

**常见病症**
| 病症 | 表现 |
| --- | --- |
| 描述内心状态 | 「他感到绝望」——摄影机拍不到 |
| 括号滥用 | 每句台词都带表演指导 |
| 抽象场景描述 | 「一个温馨的家庭场景」而不是具体的感官细节 |
| 时间线无标注 | 非线性结构没有时间层提示，读者跟丢 |

---

## 使用提醒

- **不要七维平均用力。** 每个维度都要覆盖，但篇幅要向当前最致命的问题倾斜。
- **维度之间是联动的。** 结构问题常常伪装成节奏问题；对话问题常常根源在人物欲望不清。指出联动关系，比单独修一个维度更有价值。
- **没问题的维度也要写。** 说明「为什么现在有效」，用户才知道改别的地方时不要动它。
