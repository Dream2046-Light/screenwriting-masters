# 短剧 / 短视频脚本的七维映射

七维框架来自电影和长篇剧集，但它同样适用于 60 秒短视频、3 分钟短剧、口播稿。**变的只是单位，不是原理。**

当用户提交的是短剧脚本、口播稿、分镜脚本时，按这份映射表换算，再交给大师分析。

---

## 单位换算

| 影视单位 | 短视频 / 短剧对应 |
| --- | --- |
| 一场戏 | 一个镜头组 / 一个信息单元（15–60 秒） |
| 一幕 | 一个段落（钩子段 / 展开段 / 落点段） |
| 一页 ≈ 一分钟 | 60 秒口播 ≈ 250–300 字 |
| 三幕结构 | 前 3 秒钩子 + 中段推进 + 结尾落点/转化 |
| 反转点 | 每 15 秒左右的一次信息更新或情绪转折 |
| 季 / 集 | 系列更新 / 单集 |

---

## 逐维映射

**1. 结构与节拍**
- 前 3 秒必须完成「进场即冲突」——短剧没有"慢慢进入"的预算。
- 每 15 秒设置一次微转折（新信息 / 反问 / 反转预告），这是短剧版的"节拍"。
- 结尾落点必须是一个判断或情绪状态，不是总结。

**2. 人物弧光**
- 短剧人物靠**标签 + 单一欲望**立住，不靠弧光。60 秒内做完弧光基本不可能。
- 但人物必须有**一个具体处境**，而不是"一个焦虑的年轻人"。
- 内心冲突用一句话说清：他想要 A，但他不能承受得到 A 的代价 B。

**3. 对话与潜台词**
- 口播稿的"对话"是**说给镜头外那个人听的**——要明确指出那个人是谁（一个具体的人，不是"观众"）。
- 潜台词在口播里表现为：表面上在讲道理，实际上在讲自己的某个处境。
- 声音唯一性 = 语言指纹：句式长度、口头禅、会不会用书面语、会不会骂人。

**4. 场景的进入与退出**
- 进入：第一句就要是冲突或悬念，不要自我介绍、不要"今天我们来聊聊"。
- 退出：在情绪最高点收，留一句没说完的话当钩子。
- 每个镜头组只负责一件事，不要又交代背景又推进情绪。

**5. 主题与象征**
- 主题压缩成一句话判断（"人在 X 面前会 Y"），放在结尾前。
- 象征在短剧里是一个**反复出现的视觉物件**或一个**重复句式**，出现 2–3 次即可形成积累。

**6. 类型与颠覆**
- 类型承诺 = 平台给用户的期待（爽剧要爽、知识类要给确定感、情感类要给共鸣）。
- 颠覆 = 在兑现承诺之后多给一层：爽完之后有一点疼，讲完道理之后留一个不确定。

**7. 格式**
- 口播稿标准格式：**画面 / 口播 / 字幕** 三栏对照，每行口播不超过 12 字（便于口语节奏）。
- 禁止在口播里写"他感到绝望"，改写成能被拍出来的动作或细节。
- 时长标注到秒，每段口播标注预计耗时。

## 短剧场景下的大师适配

| 想解决的问题 | 优先用谁 |
| --- | --- |
| 前 3 秒不抓人、中间掉完播 | 麦基（价值转变）+ 诺兰（信息钩子） |
| 口播像念稿、说话不像人 | 昆汀（声音唯一性） |
| 节奏拖、句子太长、没有攻守 | 索金（节奏对称性） |
| 没人看完、悬念挂不住 | 诺兰（信息地图） |
| 想做反转、荒诞、黑色幽默 | 科恩兄弟 |
| 内容太浅、只想输出观点 | 伯格曼（往下挖一层） |
| 情感太直白、煽情过猛 | 是枝裕和（删掉所有直接说出口的情感） |
| 做系列内容、账号世界观 | 大卫·西蒙（系统视角 + 长程节拍） |

---

## 注意

- **短剧不是缩水的电影。** 不要拿"三幕结构缺了第二幕"去批评一个 60 秒脚本。判断标准是：在它的时长预算内，每个单位是否都在工作。
- **完播率是短剧的结构指标。** 掉完播的位置就是节拍失效的位置——用哪个大师分析，都要把"观众会在第几秒划走"作为具体判断依据。
- **不要因为短就放过细节。** 是枝裕和的日常密度原则在 60 秒里同样成立：一个具体的感官细节比三句情绪形容词有力。
