# 世界级编剧大师 Skill

**仓库**：https://github.com/Dream2046-Light/screenwriting-masters

一个可安装的 Agent Skill：调用八位世界顶级编剧的思维模式，对剧本、大纲、人物设定、短剧脚本做**七维深度诊断**——结构 · 人物 · 对话 · 场景 · 主题 · 类型 · 格式。

不是"帮你写剧本"，是"告诉你这份稿子哪里不行、具体怎么改"。

---

## 八位大师

| # | 大师 | 派别 | 他的第一个问题 |
| --- | --- | --- | --- |
| 1 | 罗伯特·麦基 | 结构宗师 · 故事动力学派 | 每个场景的价值转变是什么？从正到负、从负到正，还是从讽刺性的正到更深的正？ |
| 2 | 昆汀·塔伦蒂诺 | 对话爆破手 · 流行文化炼金派 | 这些人说话的方式，是不是只有他们自己才会这样说？ |
| 3 | 亚伦·索金 | 台词建筑师 · 快速辩论派 | 每场戏里两个人分别在为什么而战——不是他们说的理由，而是真正的理由？ |
| 4 | 诺兰系思维 | 悬疑架构师 · 时间结构派 | 观众和主角的信息差是什么？这个信息差在什么时候、用什么方式关闭？ |
| 5 | 科恩兄弟 | 黑色幽默家 · 命运荒诞派 | 有没有什么东西是"认真得可笑"的——某个角色以为自己在掌控局面，而观众早看出他根本不在？ |
| 6 | 英格玛·伯格曼 | 灵魂拷问者 · 欧洲作者电影派 | 这个故事在触碰哪一种人类根本性的恐惧或渴望——不是角色的，而是每个现代人共有的那个？ |
| 7 | 是枝裕和 | 日常诗意家 · 东方叙事派 | 这个故事里什么东西是"缺席"的，而整个故事是否都在围绕这个缺席运转？ |
| 8 | 大卫·西蒙 | 社会系统剧作家 · 流媒体长篇叙事派 | 系统是什么？它如何迫使好人做出妥协？ |

## 用法

安装后直接说话，不需要记命令：

```
用麦基看这段剧本
这段对话帮我诊断一下          → 自动走昆汀
让三位大师会诊这份大纲
用是枝裕和的视角改这场家庭戏
帮我判断这段口播稿前3秒抓不抓人
```

**触发场景**：提交剧本片段 / 场景 / 故事大纲 / 人物设定 / 分集梗概 / 短剧脚本 / 短视频口播稿，并要求分析、诊断、改稿、润色。

### 四种模式

| 模式 | 说明 |
| --- | --- |
| **单大师精读**（默认） | 一位大师，七维全覆盖 |
| **八问快筛** | 不知道用谁时，把八位大师的"第一个问题"全问一遍，哪个最刺痛就用哪位 |
| **多大师会诊** | 2–3 位分别诊断，输出"交集报告"——两人指向同一问题，那就是核心问题；意见冲突单列为风格抉择 |
| **魔鬼代言人** | 把你最不确定的创作决定，交给最可能反对它的大师 |

### 输出长什么样

每个维度固定四段：**做对了什么 → 问题在哪 → 具体改法 → 为什么**。结尾给"下一稿只做这三件事"，以及"留着别动的"。

## 六条铁律

1. **先读完再下笔** —— 不允许凭片段臆断整体。
2. **肯定必须具体** —— 禁止"写得不错"，要说清第几场、哪句台词、为什么有效。
3. **每个问题配一个动作** —— "这里有问题"等于没说，必须是"删掉这段/改成这样/在这里加入这个"。
4. **定位要精确** —— 用场号、行号、角色名定位，不写"某处"。
5. **解释"为什么"** —— 用大师的世界观讲原理，而不是下判决。
6. **七维全覆盖** —— 没问题的维度也要说明"为什么现在有效"。

## 关于来源

本 Skill 基于一份公开流传的编剧 Prompt 整理稿《世界顶级编剧思维 Agent 系统》重构而成。原始材料是八份独立 System Prompt 的合集，本项目在其之上做了工程化改造：

- 增加**路由机制**（按症状选大师 / 八问快筛），原稿需要人工判断用谁
- 拆分为**渐进式加载**结构，原稿八份提示词需全部塞进上下文
- 增加**四种使用模式**与**标准化输出模板**
- 增加**七维检查清单**（含常见病症对照）与**短剧/短视频适配**映射

八位大师的"人格"是基于其公开作品与理论构建的**写作视角模型**，用于创作诊断，不代表其本人观点或授权。
